\# Contributing to TeamRAG



\## Git Workflow



1\. Create a new feature or bug-fix branch from `main`.

2\. Make focused changes and write clear commit messages.

3\. Run the relevant tests before submitting changes.

4\. Push the branch to GitHub.

5\. Open a pull request for review.

6\. Merge changes only after reviewing the pull request.



\## Code Quality



\- Keep changes small and understandable.

\- Never commit API keys or `.env` files.

\- Update the README when project setup or usage changes.

\- Include tests when adding or modifying functionality.
